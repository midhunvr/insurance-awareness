MALAYALAM INSURANCE AWARENESS WEBSITE

Files:
- index.html: Complete responsive website. CSS and JavaScript are included in this file.

PUBLISH WITH GITHUB PAGES:
1. Sign in to https://github.com
2. Create a new PUBLIC repository, for example: insurance-awareness
3. Upload index.html to the root of the repository (not inside another folder).
4. Open the repository's Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch: main; folder: /(root); click Save.
7. Wait for the deployment to finish. Your website address will look like:
   https://YOUR-USERNAME.github.io/insurance-awareness/
8. Open the address and test it on your phone, then share it on WhatsApp.

EDITING:
- To change the byline, search for "midhun.vr" in index.html.
- To change the Malayalam content, edit the corresponding text in index.html.
- Upload the updated index.html to GitHub to publish changes.

NOTES:
- The site is educational and uses a simplified illustrative calculator, not an actual insurance quote or claim estimator.
- Google Fonts are used for Malayalam typography; an internet connection is needed to fetch the font. The page itself otherwise runs as a static site.
- Do not add personal, customer, policy, or payment information to this public page.
